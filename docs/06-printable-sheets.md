## Sheet 5 — Switch-day checklist (the whole project, one glance)

Before the new line feels real:
- [ ] New service ordered, summary email saved
- [ ] Calendar reminder: old autopay stops
- [ ] Old provider canceled — confirmation # ________
- [ ] Old equipment returned, photo taken
- [ ] Final old-provider bill checked for strays
- [ ] New equipment activated; three speed tests logged (Sheet 2)
- [ ] Wi-Fi name/password meeting both routers, or one disabled

## The one-time money checklist (when money's the point)

- [ ] Cancelled old service (not merely "paused"?)
- [ ] Equipment fee removed (using my own box)?
- [ ] Autopay discount captured?
- [ ] Right speed tier from Guide 01's table?
- [ ] Avg24 compared across my shortlist?
- [ ] Calendar reminder set to re-shop in 24 months

## Reference block (the whole guide on one card)

- **Right size:** 1–2 people: 100–300 Mbps · family 3–4: 400–500 ·
  big house: 500–1000 · upload buyers: fiber.
- **True price:** Avg24, not the ad number. Fees + month-13 price included.
- **Boxes:** small home = own a mid-tier router · dead corners = mesh ·
  unsure = rent for now.
- **Cancel politely** with the Script 1/2 wording, get confirmation
  numbers, return equipment *with receipts*, calendar the last check.
